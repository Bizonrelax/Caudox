# Caudox

Experimental framework for geometric positional number systems and Covirtual Spaces.

## About the Project
**Caudox** is a software framework and research repository dedicated to modeling non-linear number spaces using deterministic invariants of number systems. 

The project is built upon the concept of the **Covirtual Plane** and the **IHCS** (Infinite Hierarchy of Covirtual Systems), offering an alternative geometric approach to number visualization as opposed to classical Riemannian models.

## Core Concepts
* **Digit Invariants:** Converting discrete digits into continuous spatial coordinates using parabolic vector formulas.
* **Covirtual Numbers (CVN):** Identifying and utilizing virtual attractors inside free coordinate quadrants.
* **Sign Symmetry:** Central-symmetric mirror mapping of the negative number range relative to absolute zero.

## Software Architecture
The framework is focused on developing a lightweight, cross-platform Java core for automated encoding of number arrays into multidimensional vectors, followed by graphical visualization and analytical processing.

# Caudox (Каудокс)

Experimental framework for geometric positional number systems and Covirtual Spaces.

## О проекте
**Caudox** — программный комплекс и научно-исследовательский репозиторий, посвященный моделированию нелинейных числовых пространств на основе детерминированных инвариантов систем счисления. 

В основе проекта лежит концепция **Ковиртуальной плоскости** и **БИКС** (Бесконечной Иерархии Ковиртуальных Систем), развивающая альтернативный геометрический подход к визуализации чисел взамен классической модели Римана.

## Основные положения концепции
* **Инварианты знака:** Преобразование дискретных разрядов числа в непрерывные пространственные координаты по формулам параболических векторов.
* **Ковиртуальные числа (КВЧ):** Идентификация и использование виртуальных аттракторов в свободных зонах координатных четвертей.
* **Симметрия знака:** Центрально-симметричное зеркальное отображение отрицательного диапазона чисел относительно абсолютного нуля.

## Архитектура ПО
Проект ориентирован на реализацию кроссплатформенного ядра на базе Java для автоматического кодирования числовых массивов в многомерные векторы, их визуализации и анализа.
